# Visual-Mouse-Control
Проект для управления курсором мыши с помощью жестов руки. (Python 3.8+)
__________________________
## 🚀 Возможности
- Отслеживание руки в реальном времени
- Управление движением курсора
- Левый клик при сведении указательного и среднего пальцев
- Правый клик при сведении указательного и мизинца
- Выход из программы по нажатию `0`
__________________________
## 🧠 Используемые библиотеки
- opencv-python — захват и отображение изображения
- mediapipe — распознавание и отслеживание руки
- autopy — управление мышью
- numpy — численные вычисления
__________________________
## ⚙️ Запуск проекта

    pip install -r requirements.txt
    python main.py
